# React Projects

A collection of frontend projects built using **React, JavaScript, and Tailwind CSS** to strengthen my understanding of modern web development through hands-on practice.

This repository documents my journey of learning React, building interactive user interfaces, and applying core frontend concepts to practical projects.

## Projects

### 1. Password Generator

A customizable password generator built with React and Tailwind CSS.

**Features**
- Generate random passwords.
- Customize password length using a slider.
- Toggle uppercase letters, lowercase letters, numbers, and special characters.
- Copy generated passwords to the clipboard.
- Interactive UI with a clean design.

**Concepts Learned:** React Hooks, `useState`, `useEffect`, event handling, conditional rendering, and state management.

[View Source Code](./p2_pass_generator)

### 2. Currency Converter

A currency converter interface built with React and Tailwind CSS, featuring a modern, card-inspired design.

**Features**
- Select source and target currencies.
- Enter an amount and view conversion results.
- Swap source and target currencies.
- Explore popular currency conversions.
- Switch between dark and light themes.
- Responsive and interactive user interface.

**Concepts Learned:** React Hooks, custom hooks, reusable components, props, state management, event handling, and component composition.

*Note: Currency conversion and market information features may require API integration to provide live exchange rates and news.*

[View Source Code](./p3_currency_converter)

### 3. Background Color Changer

A simple interactive application for changing the background color dynamically.

**Features**
- Change background colors through user interaction.
- Update the UI dynamically using React state.
- Explore event handling and component rendering.

**Concepts Learned:** `useState`, event handling, and dynamic styling.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Clone the Repository

```bash
git clone https://github.com/siddhexh/React_Projects.git
cd React_Projects
```

### Run a Project

For the Currency Converter:

```bash
cd p3_currency_converter
npm install
npm run dev
```

For other projects, navigate to their respective directories and follow the same process if they contain their own `package.json` files.
